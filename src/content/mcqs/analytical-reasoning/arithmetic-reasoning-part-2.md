      - None of these

R + G + B = 108 ...(i), G + R = 2B ...(ii) B = 2R ...(iii) From (ii) and (iii), we have G + R = 2x 2R = 4R or G = 3R. Putting G = 3R and B = 2R in (i), we get: R + 3R + 2R = 108 ⇔ 6R = 108 ⇔ R = 18. Therefore Number of balls in green box = G = 3R = (3 x 18) = 54."

    question: In a cricket match, five batsmen A, B, C, D and E scored an average of 36 runs. D Scored 5 more than E; E scored 8 fewer than A; B scored as many as D and E combined; and B and C scored 107 between them. How many runs did E score ?
    options:
      - "62"
      - "45"
      - "28"
      - "20"
    answer: 3
    explanation: Total runs scored = (36 x 5) = 180. Let the runs scored by E be x. Then, runs scored by D = x + 5; runs scored by A = x + 8; runs scored by B = x + x + 5 = 2x + 5; runs scored by C = (107 - B) = 107 - (2x + 5) = 102 - 2x. So, total runs = (x + 8) + (2x + 5) + (102 - 2x) + (x + 5) + x = 3x + 120. Therefore 3x + 120 =180 ⇔ 3X = 60 ⇔ x = 20.
