For the complex number 3 + 4j : Real part = 3 Imaginary part = 4 Magnitude = √(3² + 4²) = √(9 + 16) = √25 = 5 . Therefore, abs(3 + 4j) returns 5 . Hence, the correct answer is Option C: 5 ."
