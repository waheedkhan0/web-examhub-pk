    question: Opening written down value of machine 3,75,000 cost of machine 50,000 Depreciation during the year 11,500 closing written down value (WDV) of the Machine?
    options:
      - Rs. 4,25,000
      - Rs. 4,13,500
      - Rs. 3,36,500
      - None of these
    answer: 1
    explanation: "To find the closing Written Down Value (WDV), add the cost of the machine to the opening WDV and then subtract the depreciation: Opening WDV = Rs. 3,75,000 Cost of machine = Rs. 50,000 Depreciation = Rs. 11,500 Closing WDV = Opening WDV + Cost of machine - Depreciation = Rs. 3,75,000 + Rs. 50,000 - Rs. 11,500 = Rs. 4,13,500"
