    question: What is the main purpose of "data erasure" (the right to be forgotten) in data ethics and privacy?
    options:
      - To increase data accessibility
      - To protect sensitive information
      - To improve data quality
      - To allow individuals to request data removal
    answer: 3
    explanation: "Data erasure , also known as the \"right to be forgotten\" , is a core principle in data privacy laws such as the GDPR (General Data Protection Regulation). The main purpose of data erasure is to allow individuals to request the deletion of their personal data when it is no longer necessary, or when they withdraw consent. This empowers users to have control over their digital footprint and ensures that organizations respect personal privacy rights. Option A is incorrect because data erasure reduces, not increases, accessibility. Option B is incorrect because while it helps protect information, its main goal is giving users the right to request deletion. Option C is incorrect as data erasure does not directly aim to improve data quality. Therefore, the correct answer is Option D: To allow individuals to request data removal ."

    question: What is the primary goal of "data segregation" in data ethics and privacy?
    options:
      - To increase data accessibility
      - To protect sensitive information
      - To improve data quality
      - To isolate sensitive data from other data
    answer: 1
    explanation: "Data segregation refers to the practice of separating sensitive or confidential data from less critical data within systems or databases. The primary goal of data segregation is to isolate sensitive data from other data in order to enhance security and control access. By isolating sensitive information , organizations can apply stricter security measures, comply with regulations, and reduce the risk of data breaches. Option A is incorrect because increasing accessibility is not the aim of segregation—it often restricts access. Option B is close , but not as precise as Option D; while protection is a benefit, the exact goal is isolation. Option C is incorrect because improving data quality is not directly related to segregation. Therefore, the correct answer is Option D: To isolate sensitive data from other data ."
