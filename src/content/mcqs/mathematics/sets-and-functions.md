    options:
      - "{2}"
      - "{0, 2}"
      - "{-2, 2}"
      - "{ }"
    answer: 0
    explanation: The absolute value of a number is zero only if the number itself is zero. Thus, x - 2 = 0, which gives x = 2.

    options:
      - n! / r!
      - n! / (n-r)!
      - nCr
      - (n! * r!)
    answer: 1
    explanation: The formula for permutations is P(n, r) = n! / (n-r)!. It counts the number of ways to arrange 'r' items from a set of 'n' distinct items where order matters.
