## FPSC Computer Operator (BS-16) - Ministry of Defence

The **Federal Public Service Commission (FPSC)** has advertised the prestigious gazetted post of **Computer Operator (BS-16)** under the **Ministry of Defence** (**Case No. 108/2026**). This post is designated for candidates possessing a Bachelor's degree in Computer Science, Software Engineering, Information Technology, or an equivalent accredited discipline.

---

### Official Syllabus Breakdown & Weightage

FPSC conducts a single-paper 100-mark Multiple Choice Question (MCQ) objective screening test of 100 minutes duration:

#### Part-I: English (20 Marks)
- **Grammar Usage:** Active/passive voice, direct/indirect narration, prepositions, conjunctions, and conditionals.
- **Sentence Structuring:** Sentence completion, identification of grammatical errors, clause analysis, and modifiers.
- **Vocabulary:** Synonyms, antonyms, and high-frequency analytical English vocabulary.

#### Part-II: Professional Computing Domain (80 Marks)
The professional portion strictly tests the academic and practical domains of computer science:
1. **Operating Systems:** Process synchronization, semaphores, CPU scheduling algorithms, virtual memory, paging, segmentation, disk scheduling, and file systems.
2. **Algorithm Design:** Time and space complexity (Big-O notation), divide and conquer, dynamic programming, sorting and searching techniques.
3. **Database Management System (DBMS):** Relational Algebra, ER Models, Normalization (1NF, 2NF, 3NF, BCNF), Transaction ACID properties, and concurrency control.
4. **Hardware & Networking:** Network topologies, OSI seven layers, TCP/IP protocol suite, subnetting, IP addressing, switches, routers, firewalls, and hardware diagnostic procedures.
5. **Programming Languages:** Object-Oriented Programming (OOP) in C++, Python fundamentals (data structures, file I/O, libraries), and legacy Visual Basic event handling.
6. **Operating System Unix/Linux:** Linux directory hierarchy, shell scripting (Bash), file permissions (`chmod`, `chown`), process handling (`ps`, `kill`, `top`), and SSH administration.
7. **Windows 10 / 11:** Windows registry, Active Directory integration, Group Policy Objects (GPO), Task Manager diagnostics, and PowerShell administration.
8. **Oracle / PLSQL:** Writing SELECT queries, joins, subqueries, PL/SQL blocks, cursor management, exception handling, stored procedures, and triggers.
9. **System Analysis & Design:** Software Development Life Cycle (SDLC), waterfall, agile/scrum methodologies, Data Flow Diagrams (DFD), use case modeling, and testing methodologies.

### Past Paper Trend Analysis

Review of past FPSC Computer Operator and Data Processing Assistant papers reveals recurring high-frequency themes:
- **Networking:** Subnet mask calculations (e.g., finding network ID for a given /27 CIDR) and OSI layer protocols.
- **DBMS:** Questions on SQL join conditions, identifying functional dependencies, and lossless decomposition.
- **Operating Systems:** Round-robin vs. Shortest Job First scheduling calculations and page fault algorithms (FIFO, LRU).
- **Linux:** Common utility flags for `grep`, `tar`, `find`, `sed`, and understanding Unix inode structures.
- **Part-I English:** 5-6 questions on prepositions followed by 8-10 questions on sentence correction and vocabulary.
